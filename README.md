# Pure_Portfolio_Interview

KUNASAK SIRIHIRANKARN — Portfolio V1

A bilingual Thai/English React portfolio focused on software development, backend architecture, operational systems, and technical leadership.

## Run locally

1. Install Node.js (LTS).
2. Run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.

## Content notes

- Work examples and career details are based on the supplied portfolio PDF and job profile.
- Operational customer systems are described at a high level. No production links or internal credentials are included.
- Replace the contact email or revise any project wording in `src/main.jsx` before publishing.
- The portfolio avoids claiming performance metrics that were not provided.
